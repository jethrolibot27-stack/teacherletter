Teachers Card

An interactive digital greeting card created to honor Sir Randy Bello on Teachers’ Day.
This project blends creativity, technology, and gratitude — a heartfelt digital token of appreciation for a mentor who inspires through teaching, patience, and dedication.


---

💡 Overview

Teachers Card is a simple yet elegant web-based greeting card built with HTML, CSS, and JavaScript.
It delivers a warm message, beautiful design, and engaging animations to express heartfelt thanks to teachers — especially Sir Randy Bello — for their unwavering commitment to education and guidance.


---

✨ Features

🎨 Elegant Layout – Styled with CSS to look like a classic greeting card.

💬 Customizable Messages – Easily edit the message to personalize your greetings.

🎆 Interactive Animations – Fun effects using JavaScript (confetti, glowing text, or fade transitions).

💖 Responsive Design – Works beautifully on mobile and desktop.



---

🛠️ Technologies Used

HTML5 – Structure and content

CSS3 – Styling and layout

JavaScript (ES6) – Animations and interactivity
